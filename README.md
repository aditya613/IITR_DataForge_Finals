## 🌟 The Solutions

We divided our team's focus to build high-quality solutions for two distinct tracks.

### Track 1 (PS1): Hallucination Hunter 🔍
An automated fact-checking and citation system for LLM-generated content. It detects hallucinations, provides source citations, and suggests corrections using RAG (Retrieval-Augmented Generation) combined with NLI (Natural Language Inference). 
* **Tech Stack:** `sentence-transformers`, `ChromaDB`, `DeBERTa`, FastAPI
* **Key Feature:** Annotates LLM text with trust scores and highlights verifiable vs. hallucinated claims.
* 📁 **Location:** [See PS1 Directory](./PS1/)

### Track 2 (PS2): Hybrid AI Engine for Enterprise Data Migration 🏢
A complete system to automate, explain, and validate complex database migrations. It drastically reduces manual mapping effort and mitigates the massive risks associated with migrating enterprise databases.
* **Tech Stack:** FastAPI, Sentence Transformers, Groq LLM, React/Tailwind Dashboard.
* **My Contribution:** I (`aditya613`) was responsible for **solely architecting and developing the entirety of this PS2 solution**, from the core Hybrid AI matching engine down to the frontend dashboard.
* 📁 **Location:** [See PS2 Directory](./PS2/)
* 📦 **Standalone Repo:** If you're a recruiter or developer looking for just the PS2 Data Migration tool, check out my standalone repository [here](https://github.com/YourUsername/Hybrid-AI-Data-Migration).
